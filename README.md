# Daily Tech Issues

매일 한국 시간 오전 9시에 최신 테크 이슈를 한국어로 정리합니다.

## 기록 방식

- `issues/YYYY/MM/YYYY-MM-DD.md`에 이슈의 제목, 발생일, 핵심 사실, 의미, 출처 링크를 기록합니다.
- 공식 발표와 신뢰할 수 있는 보도를 확인하고 출처를 명시합니다.
- 모든 기존 기록과 제목, 출처 URL, 핵심 사건을 비교해 중복을 제외합니다.
- 같은 사건의 후속 보도는 실질적인 새 발표나 변경 사항이 있을 때만 기록하고 기존 글을 연결합니다.
- 새 이슈가 없으면 파일과 빈 커밋을 만들지 않습니다.

자동 실행은 Codex의 로컬 스케줄을 사용합니다.
