## 1. llama.cpp, 의사결정 모델 API 지원 추가

- **발생일:** 2026-10-02 원문 기준. 발표 목록에는 조사 시점 약 9시간 전 게시로 표시됐다.
- **핵심 사실:** ggml-org는 llama.cpp 서버에 `/v1/systemone` API가 추가됐다고 발표했다. 상태와 선택지를 입력하면 텍스트 생성 대신 선택지별 확률을 반환한다. 관련 구현 PR #29818은 병합 상태이며 Julia-1, Laya, Kev, lev, OpenJev 지원을 포함한다.
- **의미와 해석:** 요청 분류나 에이전트의 다음 행동 선택을 로컬 모델로 구현할 수 있는 인터페이스가 확장됐다. 반환 확률이 실제 업무의 정확도를 보장하지는 않으므로 사용 환경에서 검증해야 한다.
- **출처:** [ggml-org 발표](https://huggingface.co/blog/ggml-org/decision-models-in-llamacpp), [구현 PR](https://github.com/ggml-org/llama.cpp/pull/29818).

## 2. Ai2, 과학 문헌 보고서 모델 AstaBrief 8B 공개

- **발생일:** 2026-10-02 원문 게시일. 정확한 게시 시각과 시간대는 원문에서 확인되지 않았다.
- **핵심 사실:** Ai2는 연구 질문과 검색된 문헌 발췌로 인용을 포함한 보고서를 만드는 AstaBrief 8B와 학습 데이터를 공개한다고 발표했다. Asta의 보고서 생성 기능에서 Fast mode로 제공하며 모델을 내려받을 수 있다. Qwen3-8B를 기반으로 학습했다.
- **의미와 해석:** 과학 문헌 보고서 생성에 특화된 모델을 자체 인프라에서 운용할 수 있는 선택지가 늘었다. 발표의 평가 상당수는 2025년에 수행됐고 최신 프런티어 모델과 재평가하지 않았으므로 현재 모델 대비 성능 우위로 해석하지 않는다.
- **출처:** [Ai2 발표](https://huggingface.co/blog/allenai/astabrief), [모델 카드](https://huggingface.co/allenai/AstaBrief_8B).
