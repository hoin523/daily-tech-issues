# FLAN-T5-base: 입력을 읽는 12층과 답을 쓰는 12층

조사일: 2026-10-21 KST. ID `google/flan-t5-base`, revision `7bcac572ce56db69c1ea7c8af255c5d7c9672fc2`.

## 선정과 식별

Google의 T5 계열 instruction fine-tuning 모델이다. 용도는 지시문 기반 텍스트 변환·질문응답·번역 등이며 라이선스는 Apache-2.0이다. 정확한 기반 체크포인트 revision과 최초 HF 배포 일자는 확인 불가다. 관련 논문 최초 공개일 2022-10-20을 체크포인트 배포일과 구분한다. HF 카드는 Hugging Face 팀 작성이라고 명시한다. [고정 카드](https://huggingface.co/google/flan-t5-base/blob/7bcac572ce56db69c1ea7c8af255c5d7c9672fc2/README.md), [논문 기록](https://arxiv.org/abs/2210.11416)

조사 당시 최근 한 달 다운로드 940,185회·좋아요 1,107개를 확인했다. 좋아요 집계 기간은 확인 불가이며 인기도는 성능 증거가 아니다. [HF 페이지](https://huggingface.co/google/flan-t5-base), [API](https://huggingface.co/api/models/google/flan-t5-base)

전체 models·issues를 읽어 동일 모델 분석이 없음을 확인했다. 기존 Phi·Mistral의 decoder-only 모델과 다른 encoder-decoder 텍스트 모델을 선정했다. 큰 가중치 다운로드·추론·학습은 수행하지 않았다.

## 구조

아래 값은 [고정 config.json](https://huggingface.co/google/flan-t5-base/blob/7bcac572ce56db69c1ea7c8af255c5d7c9672fc2/config.json)과 조사 당시 API safetensors 집계에 근거한다.

| 항목 | 값 |
|---|---|
| architecture | T5ForConditionalGeneration |
| 총 파라미터 | 247,577,856 F32 원소, 약 248M |
| encoder / decoder layers | 12 / 12 |
| hidden dimension | 768 |
| FFN dimension | 2,048, gated-gelu |
| attention heads | 12; 별도 GQA KV heads 설정 없음 |
| head dimension | d_kv=64 |
| 위치 표현 | relative attention bias, 32 buckets·max_distance 128 |
| n_positions | 512, 아래 설명 참조 |
| vocab slots | 32,128 |
| LayerNorm epsilon / dropout | 1e-6 / 0.1 |
| input-output 임베딩 tie | tie_word_embeddings=false |
| MoE·멀티모달 | 없음; MoE식 활성 파라미터 구분 해당 없음 |

Encoder가 입력 문맥을 읽고 decoder는 이전 출력과 encoder 정보를 참조하여 답을 생성한다. 두 경로가 분리돼 입력 읽기와 답 쓰기의 역할을 구분한다. FFN은 gate가 있는 GELU 방식이므로 intermediate 폭만으로 일반적인 두 행렬 FFN과 파라미터를 동일 계산하면 안 된다.

Relative attention의 128은 거리 bucket 설정이며 입력 128토큰 제한이 아니다. `n_positions=512`도 absolute 위치 임베딩 테이블의 하드 상한처럼 해석하지 않는다. 상대 위치 구조가 더 긴 길이를 계산할 수 있더라도 검증된 장문 품질과 메모리 한계는 별도다. 실용 입력 길이는 tokenizer·학습 조건·실행 환경을 함께 확인해야 한다.

Config의 summarization max_length=200이나 num_beams=4는 작업별 생성 기본값이다. 구조 깊이·학습 epoch·전체 context length와 구분한다. [고정 설정](https://huggingface.co/google/flan-t5-base/blob/7bcac572ce56db69c1ea7c8af255c5d7c9672fc2/config.json)

## 학습: 사전학습과 instruction fine-tuning

다음 표는 [논문 §2.2·부록 E 표 22](https://arxiv.org/html/2210.11416v5#S0.E)의 Base 조건을 기준으로 한다. 논문 값과 HF revision의 실제 실행 로그를 직접 대조한 것은 아니다.

| 항목 | 기반 사전학습 | FLAN instruction fine-tuning |
|---|---|---|
| 목표 | span corruption 기반 T5 계열 | 지시문·정답과 일부 추론 과정 예시 학습 |
| 데이터 규모 | 해당 기반 실행 소비량 확인 불가 | 1,000개 이상 추가 과제 계열; 실제 소비 토큰 수 확인 불가 |
| epoch | 확인 불가 | 미공개 |
| optimizer steps | 확인 불가 | 논문 Base 84K |
| global batch | 확인 불가 | 64; packing으로 실제 예시 수는 더 큼 |
| learning rate | 확인 불가 | 5e-4 |
| scheduler / optimizer | 확인 불가 | constant / Adafactor |
| 학습 dropout | 확인 불가 | 0.05 |
| gradient accumulation | 확인 불가 | 확인 불가 |
| precision·하드웨어 | Base 전용 실제 실행값 확인 불가 | 카드 계열 TPU v3/v4 pods; Base 전용 구성·precision 확인 불가 |
| DPO·RL·LoRA | 적용 근거 확인 불가 | 적용 근거 확인 불가 |

계열의 큰 PaLM 모델에 사용한 TPU 수·시간을 Base에 옮기지 않았다. 배포 config dropout=0.1과 논문 fine-tuning dropout=0.05도 출처·단계가 다른 값으로 남긴다. Packing은 여러 예시를 한 sequence에 묶는 방식이어서 `84K×64`를 고유 학습 예시 수나 epoch로 환산할 수 없다.

‘미공개’는 검토한 자료에 epoch 숫자가 없다는 뜻이고 ‘확인 불가’는 조사에서 해당 실행값을 검증하지 못했다는 뜻이다. 12+12층은 깊이, step은 업데이트, epoch는 데이터 반복이다.

공식 [T5X 모델 문서](https://github.com/google-research/t5x/blob/main/docs/models.md)는 FLAN-T5 체크포인트와 코드 경로를 제공한다. 최신 예제 설정을 과거 배포 모델의 실제 실행 로그로 간주하지 않는다.

## 평가와 비교

논문은 MMLU·BBH·TyDiQA·MGSM 등을 zero-shot·few-shot·CoT 조건으로 구분한다. 카드에 인용된 Flan-PaLM 540B의 MMLU 75.2%를 FLAN-T5-base 점수로 쓰면 안 된다. 이번 조사에서는 Base별 모든 프롬프트·샷 수·디코딩 조건을 대조하지 못해 성능 순위를 제시하지 않는다. [논문 평가](https://arxiv.org/html/2210.11416v5)

추론 과정을 출력하도록 학습했다는 사실만으로 출력 논리가 항상 정확하거나 외부 사실이 검증됐다는 뜻은 아니다. 실제 업무에서는 같은 입력·출력 예산·평가 기준으로 비교해야 한다.

기존 [Phi-2 분석](2026-10-14-phi-2.md)은 32층 decoder-only base이며 instruction fine-tuning을 수행하지 않았다. 이번 모델은 12+12층 encoder-decoder이고 instruction fine-tuning을 거쳤다. 파라미터 수뿐 아니라 학습 목적·출력 형식이 달라 작다는 이유만으로 대화 품질을 단정할 수 없다.

## 활용과 제약

짧고 명확한 지시 기반 변환·분류·요약·질문응답 실험에 검토할 수 있다. 한국어 지원 언급이 있더라도 한국어 업무 품질을 보장하지 않으며 긴 문서·정확한 사실 응답은 별도 평가가 필요하다. [카드의 사용·한계](https://huggingface.co/google/flan-t5-base/blob/7bcac572ce56db69c1ea7c8af255c5d7c9672fc2/README.md)

F32 가중치만 가정하면 `247,577,856×4≈990.3 MB`(십진)다. 계산값이며 최소 VRAM·실측이 아니다. Encoder activation·decoder cache·batch·실행 버퍼가 추가된다. 속도와 정확도를 실측하지 않았다.
