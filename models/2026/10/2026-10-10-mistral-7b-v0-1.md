# Mistral-7B-v0.1: 32층 GQA와 4K 슬라이딩 윈도우

조사일: 2026-10-10 KST. 공개 자료 분석이며 가중치 다운로드·추론·학습을 수행하지 않았다.

- ID: `mistralai/Mistral-7B-v0.1`, 개발 조직 Mistral AI
- revision: `27d67f1b5f57dc0953326b2601d68371d40ea8da`
- 발표일: 2023-09-27. 논문 공개일 2023-10-10과 구분한다. [공식 발표](https://mistral.ai/news/announcing-mistral-7b/)
- 용도: 텍스트 생성 사전학습 base 모델. 별도 기반 체크포인트에서 fine-tuning됐다는 근거는 확인 불가다.
- 라이선스: Apache-2.0. [고정 모델 카드](https://huggingface.co/mistralai/Mistral-7B-v0.1/blob/27d67f1b5f57dc0953326b2601d68371d40ea8da/README.md)
- 인기 지표: 최근 한 달 다운로드 485,399회, 좋아요 4,186개. 좋아요 집계 기간은 확인 불가. [모델 페이지](https://huggingface.co/mistralai/Mistral-7B-v0.1), [API](https://huggingface.co/api/models/mistralai/Mistral-7B-v0.1)

다운로드는 성능이나 고유 사용자 수가 아니다. 기존 models·issues 전체 기록에 동일 모델·변형의 분석이 없었다. 앞선 임베딩·음성·이미지·멀티모달 분석 이후 텍스트 생성으로 돌아오되 새로운 개발 조직을 선정했다. 이 글은 최신 모델 순위가 아니라 현재 사용 관심이 남아 있는 원본 모델의 구조 분석이다.

## 구조

표의 설정은 [고정 config.json](https://huggingface.co/mistralai/Mistral-7B-v0.1/blob/27d67f1b5f57dc0953326b2601d68371d40ea8da/config.json), 파라미터 집계는 조사 당시 [HF API](https://huggingface.co/api/models/mistralai/Mistral-7B-v0.1)의 safetensors 메타데이터에 근거한다. API 지표는 시간이 지나면 바뀔 수 있다.

| 항목 | 확인값 |
|---|---|
| 유형 | MistralForCausalLM, dense decoder |
| 총 파라미터 | 7,241,732,096 (약 7.24B), API 집계 |
| 활성 파라미터 | MoE식 전문가 선택 구분 없음 |
| Transformer layers | 32 |
| hidden dimension | 4,096 |
| FFN intermediate | 14,336 |
| query / KV heads | 32 / 8 |
| head dimension | 128: 4,096÷32 계산, 논문 표 1에서도 확인 |
| attention | causal GQA + sliding-window attention |
| sliding window | 4,096 |
| max_position_embeddings | 32,768 |
| 위치 표현 | RoPE, theta=10,000 |
| 활성화 설정 | SiLU |
| normalization | RMSNorm, epsilon=1e-5 |
| 어휘 슬롯 | 32,000; byte-fallback BPE는 모델 카드 설명 |
| 입력·출력 임베딩 공유 | false |
| 저장 dtype | BF16; 실제 학습 precision을 의미하지 않음 |
| MoE·멀티모달 | 해당 없음 |

**쉬운 설명:** 32개 query head가 8개 KV head를 공유하므로 그룹당 query 수는 `32÷8=4`다. 같은 이전 토큰 정보를 여러 query가 나눠 쓰는 구조다. 슬라이딩 윈도우는 각 층에서 가까운 이전 위치를 읽는다. 이전 층이 이미 더 앞쪽 정보를 반영했으므로 영향은 층을 거치며 전달될 수 있지만 먼 원문을 직접 모두 읽는 full attention과 같지는 않다. [논문 §2](https://arxiv.org/html/2310.06825v1#S2)

### 4K·8K·32K를 구분하기

4,096은 층별 attention window다. 원 논문 표 1은 context_len을 8,192로 기록하고, 현재 고정한 HF 설정은 위치 상한을 32,768로 둔다. 둘은 출처와 의미가 다르다. 위치 상한이 곧 해당 길이에서 검증된 검색·추론 품질이라는 뜻은 아니다. 층수와 window의 곱으로 구한 이론적 정보 전달 범위도 지원 컨텍스트나 정확도 보장으로 바꿔 적지 않는다. [논문 표 1](https://arxiv.org/html/2310.06825v1#S2), [배포 설정](https://huggingface.co/mistralai/Mistral-7B-v0.1/blob/27d67f1b5f57dc0953326b2601d68371d40ea8da/config.json)

공식 발표가 연결한 [mistral-src](https://github.com/mistralai/mistral-src)는 현재 mistral-inference로 연결된다. 공개 inference 코드·설명은 확인했지만 이 체크포인트의 실제 사전학습 실행 설정이나 로그를 확인한 것은 아니다. 런타임의 window·cache 구현에 따라 메모리 동작은 달라진다.

## 학습 조건: 공개 구조에서 epoch를 역산하지 않는다

검토한 [모델 카드](https://huggingface.co/mistralai/Mistral-7B-v0.1/blob/27d67f1b5f57dc0953326b2601d68371d40ea8da/README.md), [공식 발표](https://mistral.ai/news/announcing-mistral-7b/), [기술 보고서](https://arxiv.org/html/2310.06825v1)는 이 base 체크포인트의 완전한 학습 레시피를 제공하지 않는다.

| 항목 | base v0.1 확인 상태 |
|---|---|
| 사전학습 데이터·토큰 규모 | 확인 불가 |
| epoch | 확인 불가 |
| optimizer step | 확인 불가 |
| global batch size / gradient accumulation | 확인 불가 |
| learning rate / scheduler | 확인 불가 |
| optimizer | 확인 불가 |
| 실제 학습 precision | 확인 불가 |
| 학습 하드웨어·GPU 수·시간 | 확인 불가 |
| SFT·DPO·RL·LoRA | 이 base에 적용했다는 근거 확인 불가 |

‘확인 불가’는 조사한 자료에서 체크포인트에 연결되는 값을 검증하지 못했다는 뜻이다. 별도로 공개된 Instruct 모델의 instruction fine-tuning을 이 base 모델의 후처리 단계로 옮겨 적지 않았다. 32 layers는 모델 깊이, epoch는 학습 데이터 반복 횟수, step은 optimizer 업데이트 횟수다. 생성 토큰 수나 추론 예제의 batch 설정도 학습값이 아니다.

## 평가와 비교

아래는 저자가 같은 파이프라인으로 재평가한 원 논문 표 2의 결과이며, 이번에 실측하지 않았다. [평가 조건·표 2](https://arxiv.org/html/2310.06825v1#S3)

| 모델 | MMLU (5-shot) | HumanEval (0-shot) |
|---|---|---|
| Mistral 7B base | 60.1% | 30.5% |
| Llama 2 13B base | 55.6% | 18.9% |

이 비교는 당시 두 base 모델과 논문의 조건에 한정된다. Instruct의 MT-Bench나 다른 프롬프트·디코딩 조건의 점수와 섞어 현재 우위를 주장하지 않는다. 한국어 업무 품질도 이 영어 중심 벤치마크로 판단할 수 없다.

기존 [Qwen3-8B 분석](2026-10-05-qwen3-8b.md)의 36층·32/8 heads와 비교하면 이 모델은 32층·32/8 heads다. GQA 비율은 같지만 Mistral v0.1은 4K sliding window를 설정하고 Qwen3 기록은 window 비활성화다. 층수나 attention 구조만으로 품질·지연 시간의 우열을 판단할 수는 없다.

## 실용적인 용도와 제약

텍스트 이어쓰기와 별도 fine-tuning의 출발점으로 검토할 수 있다. 대화용 instruction 모델과 구분해야 하며, 한국어 질의나 긴 문서 검색은 자신의 데이터에서 평가해야 한다. 모델 카드가 명시하듯 base에 moderation mechanism은 없다. [모델 카드](https://huggingface.co/mistralai/Mistral-7B-v0.1/blob/27d67f1b5f57dc0953326b2601d68371d40ea8da/README.md)

가중치만 BF16으로 메모리에 둔다고 가정하면 `7,241,732,096×2 = 14,483,464,192 bytes ≈ 14.48 GB`(십진)다. 이는 계산값이며 최소 VRAM이나 실측이 아니다. KV cache·activation·실행 버퍼가 추가되고 양자화·배치·컨텍스트 및 런타임에 따라 달라진다.
