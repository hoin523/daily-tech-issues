# BGE-M3: 24층 인코더 하나로 세 가지 검색을 수행하기

조사일: 2026-10-11 KST. 모델 ID `BAAI/bge-m3`, revision `5617a9f61b028005a4858fdac845db406aefb181`.

## 선정과 식별

조사 당시 최근 한 달 다운로드는 33,016,456회, 좋아요는 3,841개였다. 좋아요 집계 기간은 확인 불가이며 인기도는 정확도나 고유 이용자 수가 아니다. [모델 페이지](https://huggingface.co/BAAI/bge-m3), [API](https://huggingface.co/api/models/BAAI/bge-m3)

BAAI의 다국어 텍스트 검색 모델이며 라이선스는 MIT다. 기반 계보는 XLM-RoBERTa → bge-m3-retromae → bge-m3-unsupervised → unified fine-tuning 모델이다. 모델 카드에는 2024-02-01부터 관련 사용 소식이 있지만 정확한 최초 체크포인트 발표일은 확인 불가다. 논문 최초 공개일은 2024-02-05이며 모델 출시일과 구분한다. [고정 모델 카드](https://huggingface.co/BAAI/bge-m3/blob/5617a9f61b028005a4858fdac845db406aefb181/README.md), [논문 기록](https://arxiv.org/abs/2402.03216)

기존 models·issues 기록을 모두 확인했으며 동일 모델이나 양자화 변형의 분석은 없다. 이전 MiniLM과 같은 임베딩 분야지만 다른 조직·다국어 기반이며 검색 출력의 종류도 다르다.

### 세 출력의 역할

- **Dense:** 문서 전체 의미를 하나의 벡터로 표현한다.
- **Sparse:** 입력 토큰에 가중치를 부여해 어휘 겹침을 활용한다. BM25와 동일한 알고리즘은 아니다.
- **Multi-vector:** 여러 토큰 벡터의 상호작용으로 세부 대응을 비교한다.

이는 [모델 카드의 세 모드 사용법](https://huggingface.co/BAAI/bge-m3/blob/5617a9f61b028005a4858fdac845db406aefb181/README.md)에 근거한다. 같은 인코더를 쓰더라도 단일 dense 벡터만 저장하면 나머지 모드를 자동으로 사용할 수 있는 것은 아니다. Sparse 가중치나 multi-vector 출력, 해당 검색 인덱스를 별도로 구성해야 한다. 세 점수를 섞을 때도 척도와 가중치를 실제 검색 데이터에서 검증해야 한다.

## 학습 단계와 공개 수치

원 논문의 [부록 B.1](https://arxiv.org/html/2402.03216v1#A2.SS1)이 보고한 조건이다. 배포 체크포인트의 실제 로그를 확보한 것은 아니다.

| 항목 | RetroMAE 추가 사전학습 | 비지도 대조학습 | Unified fine-tuning |
|---|---|---|---|
| 데이터 규모 | 184M 텍스트, 105개 언어 | 단계별 데이터는 논문 표 1 참조; 실제 소비량 확인 불가 | 실제 소비량 확인 불가 |
| optimizer steps | 20,000 | 25,000 | 초기 약 6,000-step 준비 후 통합 학습; 총 step 확인 불가 |
| epoch | 미공개 | 미공개 | 미공개 |
| learning rate | 7e-5 | 5e-5 | 확인 불가 |
| batch | 32, per-device/global 구분을 이 본문에서 확정하지 않음 | 길이별 가변, 표 9 참조 | 길이별 가변, 표 9 참조 |
| gradient accumulation | 16 steps | 확인 불가 | 확인 불가 |
| scheduler | 확인 불가 | warmup ratio 0.1; 이후 scheduler 확인 불가 | 확인 불가 |
| optimizer | 확인 불가 | 확인 불가 | 확인 불가 |
| 학습 precision | 확인 불가 | 확인 불가 | 확인 불가 |
| 하드웨어 | 32 A100 40GB | 96 A800 80GB | 24 A800 80GB |
| 별도 DPO·RL·LoRA | 적용 근거 확인 불가 | 적용 근거 확인 불가 | 적용 근거 확인 불가 |

통합 fine-tuning은 여러 검색 모드의 점수를 교사 신호로 활용하는 self-knowledge distillation이다. 모델 카드의 ‘reward signal’ 표현만으로 정책 기반 RL 학습이라고 분류하지 않는다. [학습 설명](https://huggingface.co/BAAI/bge-m3/blob/5617a9f61b028005a4858fdac845db406aefb181/README.md)

‘미공개’는 검토한 논문·카드에 해당 epoch 값이 제시되지 않았다는 뜻이다. ‘확인 불가’는 이번 조사에서 검증하지 못한 값이다. Step·batch만으로 데이터 반복 횟수를 확정하지 않는다. 추론 예제의 `use_fp16=True`나 `batch_size=12`도 실제 학습 precision·batch가 아니다.

공식 [FlagEmbedding](https://github.com/FlagOpen/FlagEmbedding)과 모델 카드의 fine-tuning 링크를 조사했다. 현재 예제 경로의 웹 조회에 실패하여 코드의 실행 인자까지 확인했다고 주장하지 않는다. 위 학습값은 논문에 근거한다.

## 평가와 관련 모델 비교

공개 평가는 MIRACL 다국어 검색, MKQA 교차 언어 검색, MLDR 장문 검색을 다룬다. 모델 카드는 2024-07-01 MIRACL 결과를 수정했다고 명시한다. 이전에 query와 같은 ID의 passage를 잘못 제외했기 때문이며, 초기 논문의 점수를 수정본과 섞어 현재 순위로 쓰지 않았다. [평가 수정 설명](https://huggingface.co/BAAI/bge-m3/blob/5617a9f61b028005a4858fdac845db406aefb181/README.md)

동일한 corpus·query·관련성 라벨에서 dense 단독과 혼합 검색을 나누어 비교해야 한다. 후보 수, 평가 지표와 reranker 사용 여부도 맞춰야 한다. 이번에는 개별 평가의 최신 점수·동일 비교 조건을 모두 대조하지 못했으므로 성능 순위를 싣지 않는다.

이전 [MiniLM 분석](2026-10-06-all-minilm-l6-v2.md)은 6층·384차원·기본 입력 256 word pieces의 영어 문장 모델이다. BGE-M3는 24층·1,024차원·8,192 토큰의 다국어 검색 모델이다. 각 모델 토크나이저의 토큰 수는 동일 단위로 직접 비교할 수 없고, 벡터 차원·층수 증가만으로 품질을 보장할 수도 없다.

## 실용적인 판단

한국어를 포함한 다국어 문서 검색과 RAG의 검색 단계에서 검토할 수 있다. 답변을 작성하는 생성 LLM이나 query와 문서를 함께 읽는 cross-encoder reranker를 대신하는 모델은 아니다. 긴 문서를 한 벡터에 담는 방식과 chunk 검색을 자신의 데이터에서 비교하고, Recall@k·nDCG 및 실제 질의 실패 사례를 확인하는 편이 좋다.

검색 모드마다 인덱스 저장량과 계산량이 다르다. Dense와 multi-vector의 비용을 동일하게 가정하지 않는다. 가중치·VRAM·속도·한국어 검색 품질은 실측하지 않았으며 큰 가중치 다운로드와 유료 연산도 수행하지 않았다.
