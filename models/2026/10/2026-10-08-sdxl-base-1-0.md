# SDXL base 1.0: 두 텍스트 encoder와 다중 해상도 U-Net

조사일: 2026-10-08 KST. 모델 ID `stabilityai/stable-diffusion-xl-base-1.0`, revision `462165984030d82259a11f4367a4eed129e94a7b`.

## 선정·용도

[Hub API](https://huggingface.co/api/models/stabilityai/stable-diffusion-xl-base-1.0)에서 다운로드 4,372,699·좋아요 8,281을 확인했다. 모델 페이지의 다운로드 기간은 last month다. 인기도를 품질 점수로 취급하지 않는다. 기존 models·issues 전체 기록에 동일 모델 분석이 없으며 오늘은 이미지 분야와 Stability AI를 선정했다.

텍스트 조건 이미지 생성용 모델이며 라이선스는 CreativeML Open RAIL++-M이다. 최초 1.0 발표 일자는 이번 조사에서 확인 불가다. SDXL 보고서 v1은 2023-07-04 공개됐지만 이를 1.0 체크포인트 발표일로 치환하지 않는다. 이전 SD 모델에서 직접 fine-tuning된 체크포인트인지 확인 불가이며 두 사전학습 텍스트 encoder를 사용하는 것은 확인된다. [모델 카드](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/blob/462165984030d82259a11f4367a4eed129e94a7b/README.md), [보고서](https://arxiv.org/html/2307.01952v1).

U-Net의 attention_head_dim=[5,10,20]은 구형 Diffusers 설정 명명과 구현을 대조하지 않은 상태라 문자 그대로 head 폭이라고 단정하지 않는다. num_attention_heads=null을 attention이 없다는 뜻으로도 읽지 않는다. U-Net 전체 깊이를 목록의 단순 합으로 계산하지 않았다.

[보고서 표 1](https://arxiv.org/html/2307.01952v1#S2.SS1)은 U-Net 약 2.6B, 두 텍스트 encoder 합계 약 817M을 설명한다. 계산상 둘의 합은 약 3.417B지만 VAE는 제외되므로 전체 파이프라인 총량이 아니다. 활성 전문가 파라미터 수는 해당 없다. 카드의 base·refiner ‘experts’는 단계별 모델 조합이며 토큰별 MoE 라우팅과 다르다.

### 작동 방식

텍스트 encoder의 표현을 이미지 잠재 공간의 U-Net이 참조하며 노이즈를 줄인다. VAE decoder는 잠재 표현을 RGB 이미지로 변환한다. 두 encoder 폭의 합 `768+1280=2048`은 cross-attention 입력 차원과 맞는다. 이는 설정에 기반한 계산이다. Base만으로도 생성할 수 있고 refiner는 별도 체크포인트다. [모델 카드](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/blob/462165984030d82259a11f4367a4eed129e94a7b/README.md).

텍스트 encoder의 77 위치 슬롯과 이미지 latent sample_size=128은 서로 다른 단위다. 이 모델에 LLM의 단일 context length나 RoPE 설정을 억지로 적용하지 않는다.

## 학습 정보와 확인 한계

[보고서](https://arxiv.org/html/2307.01952v1)는 여러 해상도·종횡비와 크기·crop 조건을 활용한 학습을 설명한다. 논문 실험 설정과 배포된 1.0의 실제 학습 로그를 구분해야 한다.

| 항목 | base 1.0 전용 확인 상태 |
|---|---|
| epoch / optimizer step | 확인 불가 |
| 정확한 데이터 수·구성 | 확인 불가 |
| batch / gradient accumulation | 확인 불가 |
| learning rate·scheduler·optimizer | 실제 실행 설정 확인 불가 |
| 학습 precision·하드웨어 | 확인 불가 |
| DPO·RL·LoRA | 적용 근거 확인 불가 |

‘확인 불가’는 이번 조사에서 해당 체크포인트에 연결된 실행 설정을 확인하지 못했다는 뜻이다. `num_train_timesteps=1000`은 diffusion 시간 격자이며 1,000 optimizer steps나 epochs라는 뜻이 아니다. `num_inference_steps`는 이미지 생성 때의 반복 횟수로 또 다르다. 공개 추론 예제를 학습 로그로 사용하지 않는다.

## 비교·평가·실용적 판단

[보고서 표 1](https://arxiv.org/html/2307.01952v1#S2.SS1)은 SD 1.5의 U-Net을 약 860M, 텍스트 조건 차원을 768로 제시한다. SDXL은 더 큰 U-Net과 두 encoder가 구조적 차이다. 파라미터 증가만으로 모든 프롬프트에서 품질 향상을 보장할 수 없다.

[모델 카드](https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0/blob/462165984030d82259a11f4367a4eed129e94a7b/README.md)는 사용자 선호 평가와 구도·문자·인체 표현 한계를 설명한다. 이번 조사에서는 평가별 프롬프트 집합·표본 수·동일 sampler 조건을 직접 대조하지 못해 점수 순위를 싣지 않았다. 실제 비교는 같은 prompt·seed·해상도·생성 예산을 정하고 base와 base+refiner를 따로 측정해야 한다.

그림·디자인 시안 실험에 활용할 수 있지만 정확한 글자나 사실적 사건 재현에는 별도 검증이 필요하다. 가중치만 FP16이라 가정하면 U-Net은 `2.6B×2=5.2 GB`, 두 encoder는 `0.817B×2=1.634 GB`다. 합계 6.834 GB는 계산값이며 VAE·activation·런타임을 제외하므로 VRAM 요구량이 아니다. 큰 가중치 다운로드·유료 연산·실측은 수행하지 않았다.
