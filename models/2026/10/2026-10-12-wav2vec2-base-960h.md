# Wav2Vec2 Base-960h: 파형을 읽는 7개 합성곱 블록과 12층 Transformer

조사일: 2026-10-12 KST. 모델 ID `facebook/wav2vec2-base-960h`, revision `22aad52d435eb6dbaf354bdad9b0da84ce7d6156`.

## 선정과 식별

Meta/Facebook의 영어 음성 전사 모델이다. LibriSpeech 960시간으로 사전학습하고 전사 라벨로 fine-tuning한 base 모델이며 라이선스는 Apache-2.0이다. 정확한 최초 체크포인트 출시일은 확인 불가다. 원 논문 최초 공개일 2020-06-20을 모델 배포일로 치환하지 않는다. [모델 카드](https://huggingface.co/facebook/wav2vec2-base-960h/blob/22aad52d435eb6dbaf354bdad9b0da84ce7d6156/README.md), [논문 기록](https://arxiv.org/abs/2006.11477)

조사 시점 최근 한 달 다운로드 1,772,752회, 좋아요 407개를 확인했다. 좋아요 집계 기간은 확인 불가다. 이는 사용 관심의 신호이며 성능 증거가 아니다. [Hub 페이지](https://huggingface.co/facebook/wav2vec2-base-960h), [API](https://huggingface.co/api/models/facebook/wav2vec2-base-960h)

전체 기존 models·issues 파일을 읽어 중복 여부를 확인했다. 동일 모델 분석은 없으며 Whisper와 다른 개발 조직·음성 구조를 선정했다. 큰 가중치를 내려받거나 추론·유료 연산을 실행하지 않았다.

## 구조

아래 값은 [고정 config](https://huggingface.co/facebook/wav2vec2-base-960h/blob/22aad52d435eb6dbaf354bdad9b0da84ce7d6156/config.json), [전처리 설정](https://huggingface.co/facebook/wav2vec2-base-960h/blob/22aad52d435eb6dbaf354bdad9b0da84ce7d6156/preprocessor_config.json)과 조사 당시 API 파라미터 집계에 근거한다.

| 항목 | 확인값 |
|---|---|
| 모델 유형 | Wav2Vec2ForCTC, 음성 encoder + CTC 출력층 |
| 총 파라미터 | 94,395,552 (약 94.4M), HF safetensors 메타데이터 |
| 합성곱 특징 추출기 | 7개 블록, 각 512채널 |
| kernel widths | [10,3,3,3,3,2,2] |
| strides | [5,2,2,2,2,2,2] |
| Transformer layers | 12 |
| hidden / FFN | 768 / 3,072 |
| attention heads | 12; 별도 GQA KV heads 설정 없음 |
| head dimension | 768÷12=64, 표준 균등 분할 가정 계산 |
| activation | GELU |
| 위치 표현 | convolutional positional embedding, kernel 128·groups 16 설정 |
| 입력 | 16kHz 파형, 정규화 사용 |
| 출력 어휘 슬롯 | 32 |
| MoE·멀티모달 | 해당 없음; 전문가 활성량 구분 없음 |
| 고정 context length | config에 LLM식 최대 토큰 상한 없음. 실제 길이는 실행 메모리·분할 방식에 제약 |

논문 v1은 Base heads를 8로 기재하지만 배포 config는 12다. 이 글은 고정 revision의 체크포인트 설정인 12를 사용한다. 논문 표기와 배포값의 불일치를 숨기지 않는다. [논문 §4.2](https://arxiv.org/html/2006.11477v1#S4.SS2)

**구조 계산:** 전체 stride는 `5×2⁶=320 samples`, 16kHz에서 약 20ms 간격이다. 경계 효과를 제외하면 초당 약 50개 특징 위치가 생성된다. 이는 입력 샘플 간격 계산이며 정확한 출력 길이는 valid convolution과 입력 길이에 따라 달라진다.

파형을 합성곱으로 압축하고 Transformer가 주변 음성 문맥을 읽는다. CTC 층은 시간 위치별 문자·blank 점수를 낸다. 디코딩은 반복과 blank를 정리해 전사를 만든다. Whisper처럼 이전 문자를 하나씩 받아 다음 문자를 생성하는 별도 autoregressive decoder는 없다. [모델 카드의 argmax·batch_decode 예제](https://huggingface.co/facebook/wav2vec2-base-960h/blob/22aad52d435eb6dbaf354bdad9b0da84ce7d6156/README.md)

config의 codevector 그룹·대조학습 항목은 사전학습과 관련된 설정이다. `Wav2Vec2ForCTC` 추론에 학습용 quantizer가 모두 실행된다고 해석하지 않는다.

## 학습: 실제 기록과 공개 레시피 구분

모델 카드는 사전학습·fine-tuning 모두 LibriSpeech 960시간을 명시한다. 원 논문 Base 레시피와 공식 fairseq의 [base_960h.yaml](https://github.com/pytorch/fairseq/blob/main/examples/wav2vec/config/finetuning/base_960h.yaml)을 함께 확인했다. YAML은 움직이는 main의 공개 레시피이며 HF revision의 실제 실행 로그는 아니다.

| 항목 | Base 사전학습 논문 조건 | 960h CTC fine-tuning 공개 조건 |
|---|---|---|
| 목표 | masked latent 대조학습 | 라벨 전사를 이용한 CTC |
| 데이터 | LibriSpeech 960h | LibriSpeech 960h |
| epoch | 미공개 | 미공개 |
| steps | 논문 400,000 updates | YAML max_update=320,000, 실제 완료 step 확인 불가 |
| optimizer | Adam | Adam, YAML betas=(0.9,0.98) |
| peak learning rate | 5e-3 | 1e-4 |
| scheduler | 초기 8% warmup 후 linear decay | tri-stage 10% warmup·40% 유지·50% 감소 |
| batch 규모 | 논문 약 1.6시간 음성/global batch | 3.2M audio samples/GPU, 8GPU; 논문 총 1,600초 |
| gradient accumulation | 확인 불가 | 확인 불가 |
| hardware | 논문 64 V100 | 공개 레시피 8GPU, 구체 기종 확인 불가 |
| precision | 확인 불가 | YAML fp16=true; HF 실제 실행 precision 확인 불가 |
| SFT·DPO·RL·LoRA | 별도 적용 근거 확인 불가 | CTC 지도학습이며 LLM DPO·RL·LoRA 적용 근거 없음 |

논문 조건의 출처는 [§4.2–4.3](https://arxiv.org/html/2006.11477v1#S4)이다. Epoch 미공개는 검토한 자료에 해당 값이 없다는 뜻이며, 확인 불가는 이번 조사에서 검증하지 못했다는 뜻이다. 음성 길이별 crop·batch가 있으므로 데이터 시간과 update 수만으로 정확한 epoch를 역산하지 않았다. 12층도 학습 12회를 뜻하지 않는다.

## 평가와 비교

고정 모델 카드의 외부 LM 없이 argmax를 사용하는 LibriSpeech test 평가 예제는 WER clean 3.4%, other 8.6%를 보고한다. 이는 저자 보고값이며 실측하지 않았다. 카드가 인용한 논문 초록의 1.8/3.3 WER는 다른 모델·디코딩 조건의 대표 결과이므로 이 base 체크포인트 수치로 옮기지 않는다. [평가 코드·결과](https://huggingface.co/facebook/wav2vec2-base-960h/blob/22aad52d435eb6dbaf354bdad9b0da84ce7d6156/README.md)

같은 음성·텍스트 정규화·분할·언어 모델 조건에서 WER를 비교해야 한다. 영어 읽기 음성인 LibriSpeech 결과를 회의·잡음·한국어 전사 품질로 일반화할 수 없다.

기존 [Whisper large-v3 분석](2026-10-07-whisper-large-v3.md)은 Mel 특징과 32층 encoder·32층 decoder를 사용한다. 이번 모델은 직접 파형 특징을 추출한 뒤 12층 encoder와 CTC 층으로 전사한다. 구조·언어 범위·디코딩이 달라 파라미터만으로 정확도나 속도를 비교할 수 없다.

## 활용과 제약

영어 음성 전사 실험이나 CTC 기반 시스템 비교에 적합하다. 입력은 16kHz로 맞춰야 하며 장시간 파일은 분할·경계 처리를 검증해야 한다. 한국어 전사용으로 이 영어 체크포인트를 그대로 선택할 근거는 없다.

F32 가중치만 가정하면 `94,395,552×4 ≈ 377.6 MB`(십진)다. 계산값이며 VRAM 실측·최소 요구량은 아니다. 입력 길이·배치·attention activation·런타임 버퍼가 추가된다.
