# Phi-2: 32층 소형 언어 모델의 부분 RoPE와 데이터 반복 학습

조사일: 2026-10-14 KST. ID `microsoft/phi-2`, revision `810d367871c1d460086d9f82db8696f2e0a0fcd0`.

## 선정과 식별

Microsoft의 영어·코드 중심 base 텍스트 생성 모델이다. 라이선스는 MIT다. Phi-1.5와 데이터 계보 및 지식 전달 관계가 있으나, 단순히 같은 체크포인트의 양자화나 미러 변형은 아니다. 정확한 초기 가중치 변환·초기화 상세는 확인 불가다. [고정 모델 카드](https://huggingface.co/microsoft/phi-2/blob/810d367871c1d460086d9f82db8696f2e0a0fcd0/README.md)

공식 연구 설명 글은 2023-12-12 게시됐다. 이 날짜를 조사한 발표 문서 날짜로 기록하며, 앞선 Ignite 행사 발표나 정확한 HF 배포 일자와 동일하다고 단정하지 않는다. [Microsoft 공식 설명](https://www.microsoft.com/en-us/research/blog/phi-2-the-surprising-power-of-small-language-models/)

조사 당시 최근 한 달 다운로드 557,512회·좋아요 3,527개를 확인했다. 좋아요 집계 기간은 확인 불가이며 인기 지표는 품질의 증거가 아니다. [HF 페이지](https://huggingface.co/microsoft/phi-2), [API](https://huggingface.co/api/models/microsoft/phi-2)

전체 models·issues를 읽어 동일 모델 분석이 없음을 확인했다. 최근 음성·비전 분석 이후 새로운 개발 조직의 LLM으로 돌아왔다. 큰 가중치 다운로드·유료 연산·추론 실측은 수행하지 않았다.

## 구조

아래 설정은 [고정 config.json](https://huggingface.co/microsoft/phi-2/blob/810d367871c1d460086d9f82db8696f2e0a0fcd0/config.json), 총 파라미터 수는 조사 당시 API safetensors 집계에 근거한다.

| 항목 | 값 |
|---|---|
| 유형 | PhiForCausalLM, dense decoder |
| 총 파라미터 | 2,779,683,840 (약 2.78B); 카드의 2.7B는 요약 표기 |
| 활성 파라미터 | MoE식 전문가 선택 구분 없음 |
| layers | 32 |
| hidden / FFN intermediate | 2,560 / 10,240 |
| query / KV heads | 32 / 32 |
| head dimension | 2,560÷32=80, 균등 분할 가정 계산 |
| context / 위치 상한 | 2,048 토큰 |
| RoPE | theta=10,000; partial_rotary_factor=0.4 |
| rope_scaling | null |
| qk_layernorm | false |
| activation | gelu_new |
| LayerNorm epsilon | 1e-5 |
| 어휘 슬롯 | 51,200 |
| 임베딩 공유 | false |
| 저장 dtype | float16; 실제 학습 precision과 별개 |
| MoE·멀티모달 | 없음 |

Query와 KV heads가 같으므로 이전 Mistral·Qwen의 32/8 GQA 구성과 다르다. 동일한 head 폭·길이·dtype를 전제하면 KV head 수가 캐시 크기에 영향을 주지만 모델 전체 메모리·속도는 이것만으로 비교할 수 없다.

부분 RoPE는 head의 일부 차원에 회전 위치 표현을 적용한다. 설정과 [Transformers v4.37.0 공식 구현](https://github.com/huggingface/transformers/blob/v4.37.0/src/transformers/models/phi/modeling_phi.py)을 기준으로 계산하면 rotary 차원은 `80×0.4=32`다. 나머지 차원까지 모두 RoPE를 적용한다고 쓰지 않는다. 이는 계산값이며 성능 향상률은 측정하지 않았다.

입력 토큰은 앞선 토큰을 참조하며 32개 블록을 거쳐 다음 토큰 점수로 변환된다. 구현에서는 attention과 MLP의 출력을 잔차 경로에 함께 더하는 구성을 확인할 수 있다. Layers는 네트워크 깊이이고 학습 반복 횟수가 아니다. 모델 카드의 QA·chat 형식 예제가 instruction fine-tuning의 증거는 아니다.

## 학습 정보와 epoch 해석

표는 [고정 카드 Training 항목](https://huggingface.co/microsoft/phi-2/blob/810d367871c1d460086d9f82db8696f2e0a0fcd0/README.md)에 근거한다.

| 항목 | 공개 상태 |
|---|---|
| 사전학습 목표 | 다음 토큰 예측 |
| 데이터 규모 | 250B 토큰의 합성 NLP·필터링 웹 데이터 혼합 |
| 학습 처리량 | 1.4T 토큰 |
| epoch | 미공개 |
| optimizer step | 미공개 |
| batch / gradient accumulation | 확인 불가 |
| learning rate / scheduler / optimizer | 확인 불가 |
| 실제 학습 precision | 확인 불가 |
| 하드웨어 | 96 A100 80GB |
| 학습 시간 | 14일 |
| software | PyTorch·DeepSpeed·Flash-Attention |
| instruction SFT / RLHF | 카드·공식 설명에서 수행하지 않았다고 명시 |
| 별도 DPO·LoRA | 적용 근거 확인 불가 |

**계산과 가정:** `1.4T÷250B=5.6`이다. 두 공개 수치가 같은 토크나이저·집계 기준이고 데이터 규모가 고정됐다는 가정에서의 처리량/데이터량 비율이다. 데이터별 샘플링·재사용·혼합 비중이 공개되지 않았으므로 이를 정확히 ‘5.6 epochs 학습’으로 표기하지 않는다. Epoch는 데이터 한 바퀴, step은 optimizer 업데이트다.

‘미공개’는 검토한 카드·공식 설명에 해당 숫자가 제시되지 않았다는 뜻이고 ‘확인 불가’는 이번 조사에서 검증하지 못했다는 뜻이다. 저장 FP16이나 추론 autocast 설정으로 실제 학습 precision을 추정하지 않는다. 이번에 모델에 연결되는 완전한 학습 실행 설정·로그는 확인하지 못했다.

## 평가와 비교 조건

Microsoft의 공식 설명은 BBH, MMLU, GSM8K, HumanEval·MBPP 등 학술 평가를 제시한다. BBH는 3-shot CoT, MMLU는 5-shot 등 과제별 조건이 다르며 묶음 평균을 개별 데이터셋 점수처럼 읽으면 안 된다. 공개 벤치마크가 학습 데이터에 들어갔을 가능성도 저자가 언급한다. 재실측하지 않았으므로 현재 모델 순위나 모든 업무에서의 우위로 해석하지 않는다. [평가 설명](https://www.microsoft.com/en-us/research/blog/phi-2-the-surprising-power-of-small-language-models/)

기존 [Mistral-7B 분석](2026-10-10-mistral-7b-v0-1.md)과 비교하면 둘 다 32층이지만 Phi-2는 hidden 2,560·32/32 heads·2K context, Mistral은 hidden 4,096·32/8 heads·sliding window 구성이다. 같은 층수는 같은 계산량·품질을 의미하지 않는다.

## 활용과 제약

소형 base 모델의 영어 QA·Python 코드 생성과 fine-tuning 실험에 검토할 수 있다. 카드가 명시하듯 복잡한 지시를 따르는 능력과 영어 외 언어 처리는 제한적이다. 한국어 서비스 품질을 영어 벤치마크로 보장할 수 없으며 생성 사실·코드는 실제 작업에서 검증해야 한다. FP16 attention overflow도 카드에 알려진 실행 문제로 기록돼 있다. [제한 사항](https://huggingface.co/microsoft/phi-2/blob/810d367871c1d460086d9f82db8696f2e0a0fcd0/README.md)

FP16 가중치만 가정하면 `2,779,683,840×2≈5.56 GB`(십진)다. 계산값이며 최소 VRAM·실측이 아니다. KV cache·activation·배치·런타임 버퍼가 추가된다.
