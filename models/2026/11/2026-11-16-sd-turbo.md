# SD-Turbo: 1회 추론을 위한 diffusion distillation과 4단계 U-Net

조사일: 2026-11-16 (한국 시간). 구성·논문·코드 분석이며 큰 가중치 다운로드·이미지 생성·학습은 실행하지 않았다.

## 구성 요소별 구조

루트 `config.json` 대신 pipeline의 `model_index.json`과 각 구성 요소 설정을 확인했다.

| 구성 | 확인값 |
|---|---|
| 전체·활성 파라미터 | 가중치를 직접 집계하지 않아 확인 불가. MoE 활성 전문가 구분 없음. |
| U-Net 입력·출력 | 각각 latent 4채널, 기준 sample size 64 |
| U-Net 채널 | `[320,640,1280,1280]` |
| down block | cross-attention 3단계 + 일반 down block 1단계 |
| up block | 일반 up block 1단계 + cross-attention 3단계 |
| block 깊이 | `layers_per_block=2`, Transformer layers per block=1. 전체 U-Net이 2층이라는 뜻은 아님. |
| mid block | cross-attention mid block |
| 텍스트 조건 차원 | 1,024 |
| U-Net attention | 설정 `attention_head_dim=[5,10,20,20]`은 당시 구현에서 **head 수**로 처리. 채널÷head로 64차원 유도. |
| 텍스트 encoder | CLIPTextModel, 23층·hidden1,024·16heads·FFN4,096·최대77위치 |
| text head dimension | `1024÷16=64`, 계산값 |
| VAE | RGB↔4채널 latent, 채널 `[128,256,512,512]`, block당2층 |
| VAE scaling | 0.18215, `force_upcast=true` |
| scheduler | EulerDiscreteScheduler, epsilon prediction, trailing spacing |

근거: [pipeline](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/model_index.json), [U-Net](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/unet/config.json), [VAE](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/vae/config.json), [텍스트 encoder](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/text_encoder/config.json), [scheduler](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/scheduler/scheduler_config.json), [Diffusers v0.24.0 U-Net 구현](https://github.com/huggingface/diffusers/blob/v0.24.0/src/diffusers/models/unet_2d_condition.py). attention 설정의 역사적인 이름을 숫자 그대로 head dimension으로 오독하지 않았다.

텍스트 encoder가 prompt를 조건 벡터로 만들고, U-Net이 노이즈 latent를 이미지 latent로 바꾼다. VAE decoder가 이를 픽셀로 복원한다. U-Net의 down/up 경로와 skip connection은 서로 다른 해상도의 정보를 연결한다. 카드의 single-step은 주로 denoiser 호출 횟수이며 텍스트 처리·VAE 복원까지 모든 계산이 한 연산이라는 뜻은 아니다. [pipeline 구성](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/model_index.json), [카드](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/README.md)

512×512 이미지에 대응하는 기준 latent는 64×64다. 이는 공간 축 8배 압축이라는 대응이며 압축이 무손실이라는 뜻은 아니다. VAE config의 `sample_size=768`을 근거로 SD-Turbo의 권장 출력이 768이라고 쓰지 않았다. 실제 사용 안내와 각 구성 요소의 설정을 구분했다. [VAE](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/vae/config.json), [카드](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/README.md)

## 학습: ADD의 역할과 미공개 값

| 단계·항목 | 확인 내용 |
|---|---|
| 기반 사전학습 | Stable Diffusion 2.1, 원 실행의 데이터·epoch·step·batch·하드웨어는 이번 조사에서 확인 불가 |
| 증류 방식 | Adversarial Diffusion Distillation (ADD), diffusion teacher 신호와 adversarial loss 결합 |
| epoch / optimizer update | 해당 SD-Turbo 실행값 미공개 |
| 데이터 규모 / batch / accumulation | 해당 실행 대응값 확인 불가 |
| optimizer / LR / schedule | 해당 실행 대응값 확인 불가 |
| 학습 precision / 하드웨어 | 해당 실행 대응값 확인 불가 |
| SFT·DPO·RL·LoRA | 본 배포 모델의 단계로 보고되지 않음 |

근거: [카드 학습 방식 설명](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/README.md), [ADD 논문 §3](https://arxiv.org/html/2311.17042v1). 일반 diffusion 프레임워크가 제공된다는 사실을 완전한 SD-Turbo 실행 recipe 공개와 같게 보지 않았다.

ADD는 여러 번의 denoising이 필요했던 모델을 적은 호출로 좋은 이미지를 만들도록 학습한다. 고정된 diffusion teacher와의 증류 신호가 구조·조건 이해를 유지하도록 돕고, discriminator의 적대적 신호는 이미지의 외관을 개선하는 역할을 한다. 배포 pipeline에 discriminator가 없다고 학습에서도 없었다는 뜻은 아니다. [논문 §3](https://arxiv.org/html/2311.17042v1)

scheduler의 `num_train_timesteps=1000`은 노이즈 시점 격자다. **1,000번 학습했다는 뜻이 아니다.** 카드 예제의 `num_inference_steps=1`도 학습 epoch가 아니다. 모델 구조·노이즈 시점·optimizer update·sampling step을 각각 구분해야 한다. [scheduler](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/scheduler/scheduler_config.json)

## 평가와 활용 범위

카드는 SD-Turbo 1-step의 이미지 품질·prompt 일치에 대한 사람 선호 비교를 제시한다. ADD 논문의 ADD-XL·SDXL 결과를 이 작은 SD-Turbo의 점수로 옮기지 않았다. 사람이 비교한 조건과 step 수에 의존하는 결과이며 모든 prompt에서 우월하다는 뜻은 아니다. [고정 카드 평가](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/README.md#evaluation), [논문 평가](https://arxiv.org/html/2311.17042v1)

카드 사용 예제는 `guidance_scale=0.0`이며 negative prompt와 CFG를 쓰지 않는다고 명시한다. 일반 SD의 CFG 값을 그대로 적용해 동일 동작을 기대하면 안 된다. 텍스트·얼굴 표현과 사실 재현의 한계도 카드에 명시되어 있다. [사용·한계](https://huggingface.co/stabilityai/sd-turbo/blob/b261bac6fd2cf515557d5d0707481eafa0485ec2/README.md)

아이디어 시안과 빠른 생성 인터랙션을 검토하는 연구에 쓸 수 있다는 것이 이번 분석의 해석이다. [SDXL base](../10/2026-10-08-sdxl-base-1-0.md)의 품질·prompt 이해와 이 모델의 낮은 호출 수를 같은 비용 조건에서 직접 비교한 것은 아니다. 1-step이라는 이유만으로 특정 장치의 실시간 속도·VRAM을 보장하지 않는다.

출처·구성·중복을 검토했다. 실측하지 않은 생성 품질·속도·메모리 수치는 제시하지 않는다.
