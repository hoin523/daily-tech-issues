## 구조

| 항목 | 확인값 |
|---|---|
| 깊이 / hidden | 12층 / 768 |
| attention 구성 | global, local 순서를 6회 반복. 각각 6층 |
| local window | 256, 전체 모델의 최대 입력 길이와 구분 |
| 최대 위치 | 2,048 |
| attention / KV heads | 표준 MHA Q·K·V 각각 12개 |
| head dimension | `768÷12=64`, 구성에서 계산 |
| FFN 중간 차원 | 3,072. `intermediate_size=null`일 때 코드가 `4×hidden_size` 사용 |
| 활성화 / 정규화 | gelu_new / pre-LayerNorm, epsilon 1e-5 |
| 위치 표현 | 학습 가능한 absolute position embedding |
| 어휘 | 50,257 |
| dropout | attention·embedding·residual 각각 0 |
| MoE / 멀티모달 | 없음 |
| 저장 규모 | API F32 원소 125,198,592, U8 원소 25,165,824. U8 attention mask buffer까지 더한 150,364,416을 trainable parameter 수로 쓰지 않는다. |

근거: [고정 config](https://huggingface.co/EleutherAI/gpt-neo-125m/blob/21def0189f5705e2521767faed922f1f15e7d7db/config.json), [Transformers v4.9.0 구현](https://github.com/huggingface/transformers/blob/v4.9.0/src/transformers/models/gpt_neo/modeling_gpt_neo.py), [API](https://huggingface.co/api/models/EleutherAI/gpt-neo-125m). 라이브러리 태그는 구조 확인용이며 원 학습 설정이 아니다. 실제 학습 가능한 전체 계수를 가중치로 직접 집계하지 않았다.

모든 층은 미래 토큰을 보지 않는 causal 방식이다. global 층은 사용 가능한 과거 범위 전체를, local 층은 제한된 가까운 범위를 읽는다. local window 256을 이유로 모델 전체가 과거 256토큰만 참고한다고 해석하면 안 된다. global 층이 사이에 배치되어 넓은 범위의 정보를 전달하기 때문이다. [구성](https://huggingface.co/EleutherAI/gpt-neo-125m/blob/21def0189f5705e2521767faed922f1f15e7d7db/config.json), [attention 구현](https://github.com/huggingface/transformers/blob/v4.9.0/src/transformers/models/gpt_neo/modeling_gpt_neo.py)

각 블록은 LayerNorm → attention → residual addition, 다시 LayerNorm → FFN → residual addition을 수행한다. 마지막 표현으로 다음 토큰을 예측한다. 카드의 “masked autoregressive”는 이 문맥에서 미래를 가리는 언어 모델을 뜻하며, BERT처럼 임의로 지운 토큰 복원을 수행하는 양방향 모델로 해석하지 않았다. [구현](https://github.com/huggingface/transformers/blob/v4.9.0/src/transformers/models/gpt_neo/modeling_gpt_neo.py), [학습 목적](https://huggingface.co/EleutherAI/gpt-neo-125m/blob/21def0189f5705e2521767faed922f1f15e7d7db/README.md#training-procedure)

## 학습 이력과 공개 설정의 불일치

| 항목 | 이 체크포인트에 대해 확인한 내용 |
|---|---|
| 사전학습 데이터 / 토큰 | The Pile / 카드상 300B tokens |
| 학습 step | 572,300 |
| epoch | 미공개. 토큰 규모나 layer 수로 추정하지 않음. |
| batch / accumulation | 체크포인트 대응값 확인 불가 |
| optimizer / LR / scheduler | 체크포인트 대응값 확인 불가 |
| precision / 하드웨어 | 체크포인트 대응값 확인 불가 |
| 학습 목적 | 다음 토큰 예측, cross-entropy |
| SFT·DPO·RL·LoRA | 해당 후속 학습을 수행한 모델로 보고되지 않음 |

근거: [고정 카드 학습 절](https://huggingface.co/EleutherAI/gpt-neo-125m/blob/21def0189f5705e2521767faed922f1f15e7d7db/README.md#training-procedure).

공식 저장소의 [gpt3_small_256.json](https://github.com/EleutherAI/gpt-neo/blob/23485e3c7940560b3b4cb12e0016012f14d03fc7/configs/gpt3_small_256.json)은 깊이 12·hidden 768·572,300 step을 갖는다. 그러나 데이터가 `openwebtext-documents`, attention은 global-only이며, HF config는 global/local 교대이고 카드는 Pile 학습을 명시한다. 따라서 이 파일의 Adam·LR 0.0006·batch 256·cosine schedule을 해당 HF 모델의 확정 recipe로 복사하지 않았다. 이름과 일부 숫자가 같아도 동일 실행의 증거는 아니다.

`300B÷572,300 ≈ 524,200 token/step`은 반올림된 카드 수치에서 얻는 대략적인 산술값일 뿐이다. 이를 정확한 batch나 고유 데이터 반복 횟수로 바꾸지 않는다. 원 학습 로그와 완전히 일치하는 설정 파일은 이번 조사에서 확인하지 못했다.

## 평가와 활용 범위

카드에는 Open LLM Leaderboard 계열 결과로 HellaSwag **30.26 (10-shot)**, ARC **22.95 (25-shot)** 등이 기록되어 있다. 서로 다른 few-shot 조건의 과제를 포함한 과거 보고값이며, 현재 순위나 직접 재현한 정확도가 아니다. 원 카드의 별도 평가 절에는 TBD도 남아 있어 결과의 출처·조건을 함께 읽어야 한다. [고정 평가 표](https://huggingface.co/EleutherAI/gpt-neo-125m/blob/21def0189f5705e2521767faed922f1f15e7d7db/README.md)

소형 causal LM의 attention mask·KV cache·미세조정 실험을 공부하는 출발점으로 쓸 수 있다는 것이 이번 분석의 해석이다. 지시 이행이나 대화 선호도 학습을 받은 체크포인트로 소개되지 않으므로 최신 채팅 모델의 능력을 기대하는 용도로 추천하지 않는다. 웹·문헌 혼합 데이터의 편향과 부적절한 출력 가능성도 카드에 명시되어 있다. [공식 용도·한계](https://huggingface.co/EleutherAI/gpt-neo-125m/blob/21def0189f5705e2521767faed922f1f15e7d7db/README.md#intended-use-and-limitations)

[GPT-Neo와 별도인 Pythia](2026-11-01-pythia-70m.md)의 중간 checkpoint 분석과 비교하면, 공개 학습 step이 있다는 사실과 실행 설정 전체가 재현 가능하다는 사실이 다름을 볼 수 있다. [ModernBERT](../10/2026-10-24-modernbert-base.md)도 지역·전역 attention을 쓰지만 양방향 encoder이므로 생성 목적·mask를 혼동하면 안 된다.

사실·출처·중복 여부를 검토했다. 실제 속도·VRAM·생성 품질을 측정하지 않았으며 이를 실측값으로 제시하지 않는다.
