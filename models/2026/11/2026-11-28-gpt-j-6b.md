# GPT-J-6B: 28층 언어 모델과 head 일부에 적용되는 RoPE

조사일: 2026-11-28 (한국 시간). 가중치 다운로드·추론·학습 없이 공개 구성과 학습 설정을 분석했다.

## 구조

| 항목 | 확인값 |
|---|---|
| 총 trainable 파라미터 | 카드 보고 6,053,381,344. 직접 로딩 재집계 안 함 |
| 유형·깊이 | Dense causal decoder, 28층 |
| hidden / FFN | 4,096 / 16,384, GELU 계열 |
| attention / KV heads | 표준 MHA 16개, KV도 16개 |
| head dimension | 256 (`4096÷16`) |
| 위치 표현 | 각 head의 64차원에 RoPE 적용, 전체 head의 25% (`64÷256`) |
| context | 2,048 position |
| vocab | embedding 행 50,400, GPT-2 tokenizer 실제 어휘 50,257 |
| 임베딩 공유 | tie_word_embeddings false |
| dropout | attention·embedding·residual 모두 0.0 |
| LayerNorm epsilon | 1e-5 |
| MoE·멀티모달 encoder | 없음 |

[config](https://huggingface.co/EleutherAI/gpt-j-6b/blob/47e169305d2e8376be1d31e765533382721b2cc1/config.json), [구조 표](https://huggingface.co/EleutherAI/gpt-j-6b/blob/47e169305d2e8376be1d31e765533382721b2cc1/README.md). `n_inner=null`은 FFN이 없다는 뜻이 아니다. 카드에서 16,384를 별도로 확인했다. `max_length=50`은 생성 예시 설정이며 context 2,048과 다르다.

각 층은 앞선 토큰만 참고하는 self-attention과 feedforward 계산을 포함한다. RoPE는 토큰 위치를 반영하지만 이 모델에서는 head 전체 256차원을 회전시키지 않는다. 따라서 rotary_dim 64를 hidden 64 또는 head dimension 64로 잘못 읽지 않아야 한다. [카드·원 구현 연결](https://huggingface.co/EleutherAI/gpt-j-6b/blob/47e169305d2e8376be1d31e765533382721b2cc1/README.md)

## 실제 학습 보고와 공개 recipe

| 항목 | 카드의 실제 학습 보고 / 공개 config |
|---|---|
| 데이터 | The Pile |
| 소비 토큰 / step | 카드: 약 402B tokens / 383,500 steps |
| epoch | 명시값 확인 불가. 데이터셋 용량 GB에서 토큰 epoch를 추정하지 않음 |
| 장비 | 카드: TPU v3-256 pod |
| accumulation | 공개 config: 16 |
| batch 관련 | 공개 config: per_replica_batch 1, cores_per_replica 8, tpu_size 256. 실제 전역 batch는 코드의 배치·shard 의미 확인 없이 단정하지 않음 |
| LR | 공개 config 1.2e-4, end_lr 1.2e-5 |
| warm-up / anneal | 공개 config 3,000 / 300,000 steps. 전체 곡선 형태는 이 파일만으로 확정 안 함 |
| weight decay | 공개 config 0.1 |
| optimizer / precision | 원 실행 세부 optimizer·정밀도 구성 확인 불가 |
| SFT·DPO·RL·LoRA | 오늘 사전학습본에 해당 후속 단계 미적용으로 구분 |

[카드 Training procedure](https://huggingface.co/EleutherAI/gpt-j-6b/blob/47e169305d2e8376be1d31e765533382721b2cc1/README.md), [고정 원본 설정](https://raw.githubusercontent.com/kingoflolz/mesh-transformer-jax/f8315e3003033b23f21d78361b288953064e0e76/configs/6B_roto_256.json). config의 `total_steps=350000`은 카드의 실제 보고 383,500과 다르다. 이 파일을 최종 실행 로그로 취급하거나 두 숫자를 임의로 맞추지 않았다. 공개 config는 재현 참고 자료이며 개별 HF revision의 모든 학습 이력을 증명하지 않는다.

402B는 반올림된 학습 소비량이다. 이를 step으로 나눈 값을 정확한 batch 크기라고 주장하지 않는다. 28층은 구조 깊이이고 3,000 warm-up step이나 생성 토큰 수는 epoch가 아니다.

## 평가·비교·활용

카드의 zero-shot 평가표는 LAMBADA perplexity **3.99**, accuracy **69.7%**, HellaSwag **66.1%**, PIQA **76.5%**를 보고한다. perplexity는 낮을수록 좋으며 accuracy와 같은 지표가 아니다. 카드에 따르면 lm-evaluation-harness 결과와 타 연구진 보고가 혼합되어 있고 prompt framing·구현 차이 때문에 직접 비교에 한계가 있다. Pile이 평가 test set과 중복 제거되지 않아 오염 가능성도 명시되어 있다. [평가 표·주석](https://huggingface.co/EleutherAI/gpt-j-6b/blob/47e169305d2e8376be1d31e765533382721b2cc1/README.md)

이는 카드의 역사적 보고값이며 해당 revision을 현재 평가 도구로 재현한 결과가 아니다. 대화 지시 준수·한국어 품질·사실성을 나타내는 점수도 아니다. 카드 자체가 영어 데이터 사전학습과 후속 학습 부재를 설명한다. [용도·제약](https://huggingface.co/EleutherAI/gpt-j-6b/blob/47e169305d2e8376be1d31e765533382721b2cc1/README.md)

기존 [GPT-Neo 125M](2026-11-10-gpt-neo-125m.md)과 [Pythia-70M](2026-11-01-pythia-70m.md)은 크기·attention·학습 이력이 다른 모델이다. GPT-J의 점수를 이들 모델에 옮기지 않는다. 분석상 전통적인 중형 causal LM 구조와 추가 학습 실험의 기준점으로 활용할 수 있지만 최신 지시형 모델을 대표하지 않는다. 속도·VRAM·사용자 prompt 정확도는 실측하지 않았다.
