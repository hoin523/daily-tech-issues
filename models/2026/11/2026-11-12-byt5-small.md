# ByT5-small: 바이트 입력과 12:4 encoder·decoder 구조

조사일: 2026-11-12 (한국 시간). 가중치 다운로드·학습·추론 없이 구성과 공식 자료를 분석했다.

## 구조와 attention 차원

| 항목 | 확인값 |
|---|---|
| 파라미터 | 공식 표 약 300M. 정밀한 정수 총량과 trainable 전체 계수는 이번 조사에서 확인 불가. Dense, MoE 없음. |
| encoder / decoder | 12층 / 4층 |
| hidden `d_model` | 1,472 |
| FFN `d_ff` | 3,584, gated-gelu |
| attention heads / KV heads | 표준 MHA 각각 6개 |
| head dimension `d_kv` | **64**, config 명시값 |
| attention 내부 투영 차원 | `6×64=384`. hidden 1,472와 다르며 `1472÷6`으로 head dimension을 구하지 않는다. |
| 위치 표현 | T5 계열 relative attention bias, bucket 32개 |
| 어휘 | 384, 원시 byte 256개 외 특수·예약 ID 포함 |
| dropout / 정규화 epsilon | 0.1 / 1e-6 |
| 입출력 embedding | `tie_word_embeddings=false`, LM 출력 가중치 비공유 설정 |
| 사전학습 입력 길이 | 1,024 byte 단위 위치. 전체 모델의 영구적인 하드 최대 문맥으로 단정하지 않음. |

근거: [고정 config](https://huggingface.co/google/byt5-small/blob/68377bdc18a2ffec8a0533fef03b1c513a4dd49d/config.json), [T5 attention·FFN 구현](https://github.com/huggingface/transformers/blob/v4.7.0/src/transformers/models/t5/modeling_t5.py), [공식 크기 목록](https://github.com/google-research/byt5/blob/7d4efdddf7049a2aadfe65d032f264553508916e/README.md). 라이브러리 태그는 구조 확인용이며 원 학습 코드 commit을 의미하지 않는다.

encoder는 입력의 앞뒤를 함께 보고, decoder는 이전 출력과 encoder 표현을 참고해 다음 byte ID를 예측한다. 작은 어휘에서 절약한 계수를 넓은 Transformer 계층에 배분하고 encoder를 더 깊게 둔 설계다. 숨은 표현의 폭과 attention의 Q·K·V 투영 폭을 별도로 두는 점이 일반적인 “hidden÷heads” 설명과 다르다. [구현](https://github.com/huggingface/transformers/blob/v4.7.0/src/transformers/models/t5/modeling_t5.py), [논문 §3](https://arxiv.org/html/2105.13626v1)

`tokenizer-free`는 학습된 subword 분절 어휘가 필요 없다는 뜻이다. UTF-8 인코딩과 특수 토큰 처리까지 없다는 뜻은 아니다. 카드 예제는 raw byte 값에 3을 더해 ID로 쓰며, 배치의 padding 처리를 위해 ByT5Tokenizer 사용도 안내한다. [고정 사용 예](https://huggingface.co/google/byt5-small/blob/68377bdc18a2ffec8a0533fef03b1c513a4dd49d/README.md#example-inference)

예를 들어 한글 완성형 ‘가’는 UTF-8 3byte이고 ASCII ‘A’는 1byte다. 따라서 1,024개 위치가 1,024자 또는 1,024단어라는 뜻은 아니다. 동일한 문장이라도 subword 모델보다 입력·출력 시퀀스가 길어질 수 있다.

## 학습 설정과 공개 범위

| 항목 | 사전학습 공개 내용 |
|---|---|
| 데이터 | 다국어 mC4 |
| 목적 | span corruption, 평균 mask span 약 **20byte**. 카드의 character 표현과 달리 논문은 byte 단위로 설명. |
| step | 1,000,000 |
| batch | 2²⁰=1,048,576 위치/token 단위, byte 모델의 단위로 읽기 |
| 입력 길이 | 1,024 |
| epoch | 미공개. step·batch에서 고유 corpus 반복 횟수를 추정하지 않음. |
| optimizer / LR | Small 실행에 대응하는 상세값 확인 불가 |
| scheduler | 공식 Large 예제는 `rsqrt_no_ramp_down`. Small의 실제 실행과 동일하다고 확정하지 않음. |
| accumulation / precision / 장비 | Small 실행 대응값 확인 불가 |
| SFT·DPO·RL·LoRA | 이 체크포인트에는 지도 downstream 학습이 포함되지 않음 |

근거: [카드](https://huggingface.co/google/byt5-small/blob/68377bdc18a2ffec8a0533fef03b1c513a4dd49d/README.md), [논문 §3.1](https://arxiv.org/html/2105.13626v1), [공식 학습 예제](https://github.com/google-research/byt5/blob/7d4efdddf7049a2aadfe65d032f264553508916e/README.md). 저장소의 TPUv3-256·targets=189 예제는 명시적으로 Large용이므로 Small의 장비·설정으로 옮기지 않았다.

`1,000,000×1,048,576=1,048,576,000,000`은 명시 batch 단위를 곱한 산술값이다. 특수 토큰·padding·샘플링을 구분하지 못하므로 실제 고유 UTF-8 원문량이라고 쓰지 않는다. 12층·4층은 네트워크 깊이이고 생성 길이나 학습 횟수와도 다르다.

## 평가와 실용적인 제약

논문 Table 2의 ByT5-small GLUE **80.5**, SuperGLUE **67.8**은 과제별 지도 미세조정 후 validation 집계다. 이 사전학습 가중치를 그대로 실행한 zero-shot 점수로 해석하면 안 된다. 같은 표의 mT5-small 비교도 당시의 학습·평가 조건에 한정된다. [논문 Table 2](https://arxiv.org/html/2105.13626v1)

철자·노이즈에 민감한 짧은 텍스트 변환 작업의 미세조정 출발점으로 사용할 수 있다는 것이 이번 분석의 해석이다. byte를 처리할 수 있다는 사실만으로 모든 언어에서 같은 품질을 보장하지 않으며, 사전학습본은 번역·요약용 미세조정이 필요하다고 카드가 명시한다. [카드](https://huggingface.co/google/byt5-small/blob/68377bdc18a2ffec8a0533fef03b1c513a4dd49d/README.md)

[FLAN-T5-base](../10/2026-10-21-flan-t5-base.md)는 instruction tuning을 받은 subword 모델인 반면, 오늘 모델은 byte 기반 사전학습본이다. 문자열 표현을 단순화하는 이점과 길어진 시퀀스의 계산 비용을 함께 고려해야 한다. 이번에는 처리 속도·VRAM·한국어 품질을 측정하지 않았다.

원문 링크·값·중복 여부를 검토했으며 계산값과 공식 보고값을 분리했다.
