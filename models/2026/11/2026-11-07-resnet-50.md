# ResNet-50 v1.5: 16개 잔차 블록과 4단계 합성곱 구조

조사일: 2026-11-07 (한국 시간). 가중치 다운로드·추론·학습 없이 공개 설정과 구현을 분석했다.

## 선정과 식별

`microsoft/resnet-50`은 조사 시점 Hugging Face 최근 한 달 다운로드 **221,096회**, 누적 좋아요 **530개**였다. 트렌딩 순위를 확인했다는 뜻은 아니며, 지속적으로 사용되는 이미지 분류 모델을 선택한 근거다. 다운로드·좋아요는 정확도 지표가 아니다. [모델 페이지](https://huggingface.co/microsoft/resnet-50), [API](https://huggingface.co/api/models/microsoft/resnet-50)

| 항목 | 확인 내용 |
|---|---|
| 모델 | `microsoft/resnet-50`, ImageNet-1k 분류용 ResNet-50 v1.5 |
| 분석 revision | `34c2154c194f829b11125337b98c8f5f9965ff19` |
| 계보 | Microsoft Research의 ResNet 연구 기반. 카드는 Hugging Face 팀 작성본이라고 명시한다. |
| 발표 / 조사 | 원 논문 최초 제출 2015-12-10 / 조사 2026-11-07. 원 논문 날짜를 이 변환 체크포인트 출시일로 쓰지 않는다. |
| HF 저장소 생성 | API상 2022-03-16. 가중치의 원 학습일·최초 공개일은 확인 불가. |
| 기반 데이터 / 라이선스 | ImageNet-1k / 카드상 Apache-2.0 |

근거: [고정 카드](https://huggingface.co/microsoft/resnet-50/blob/34c2154c194f829b11125337b98c8f5f9965ff19/README.md), [API](https://huggingface.co/api/models/microsoft/resnet-50), [논문](https://arxiv.org/abs/1512.03385).

기존 `models`·`issues` 전체를 읽었다. [DETR 분석](../10/2026-10-29-detr-resnet-50.md)에서 ResNet을 backbone으로 언급했지만 이 분류 체크포인트나 잔차 블록 자체를 분석하지는 않았다. DETR의 탐지 head·Transformer와 다른 모델이며 양자화·미러를 새 모델로 취급한 것이 아니다.

## 구조: 50층과 16개 블록을 구분하기

[고정 config](https://huggingface.co/microsoft/resnet-50/blob/34c2154c194f829b11125337b98c8f5f9965ff19/config.json)와 [Transformers v4.18.0 구현](https://github.com/huggingface/transformers/blob/v4.18.0/src/transformers/models/resnet/modeling_resnet.py)을 대조했다. 코드 태그는 구조 해석에 사용한 라이브러리 버전이며 원 학습 코드의 commit을 뜻하지 않는다.

| 구성 | 값 |
|---|---|
| 입력 | RGB 3채널, 카드의 기준 해상도 224×224 |
| stem | 7×7 convolution, 64채널, stride 2 → 3×3 max pooling, stride 2 |
| stage별 블록 수 | `[3,4,6,3]`, 합계 16개 bottleneck |
| stage 출력 채널 | `[256,512,1024,2048]` |
| bottleneck 내부 채널 | 출력의 1/4인 `[64,128,256,512]` |
| 블록 내부 | 1×1 축소 → 3×3 공간 처리 → 1×1 확장, BatchNorm·ReLU |
| 축소 위치 | 첫 stage는 stride 1, 이후 stage 첫 블록에서 stride 2 |
| v1.5 차이 | 공간 축소 stride를 첫 1×1이 아닌 3×3 convolution에 둔다. |
| 마지막 | 공간 평균 pooling → 2,048차원 → 1,000개 클래스 선형 분류 |
| attention / 위치 encoding / MoE | 사용하지 않는 CNN. KV heads·문맥 길이는 해당 없음. |
| 저장 텐서 규모 | Hub safetensors API 집계 F32 원소 25,610,152개. BatchNorm 통계 등 buffer와 학습 가능한 계수를 구분한 직접 집계는 확인 불가. |

근거: [config](https://huggingface.co/microsoft/resnet-50/blob/34c2154c194f829b11125337b98c8f5f9965ff19/config.json), [공식 라이브러리의 stem·bottleneck·stage·분류 구현](https://github.com/huggingface/transformers/blob/v4.18.0/src/transformers/models/resnet/modeling_resnet.py), [v1.5 카드 설명](https://huggingface.co/microsoft/resnet-50/blob/34c2154c194f829b11125337b98c8f5f9965ff19/README.md). API의 원소 수를 그대로 trainable parameter 수로 단정하지 않았다.

224×224 입력과 구현의 padding·stride를 적용하면 stage 공간 크기는 **56×56 → 28×28 → 14×14 → 7×7**로 계산된다. 채널은 늘리고 공간은 줄여 장면을 압축한다. 이는 구성에서 유도한 모양이며 실행으로 측정하지 않았다.

이름의 50은 주 경로의 stem 1층 + 블록당 convolution 3층 × 16 + 분류 선형층 1층, 즉 `1+3×16+1=50`이라는 관례다. projection shortcut의 convolution과 BatchNorm까지 모든 연산을 센 숫자가 아니다. **50 epoch라는 뜻도 아니다.** [원 논문 구조 표](https://arxiv.org/html/1512.03385v1), [구현](https://github.com/huggingface/transformers/blob/v4.18.0/src/transformers/models/resnet/modeling_resnet.py)

블록이 새 표현 전체를 다시 만들기보다 입력에 더할 변화량을 학습하도록 한다. 같은 모양이면 입력을 그대로 더하고, 채널·해상도가 바뀌면 1×1 shortcut으로 모양을 맞춘다. 구현의 출력은 `ReLU(F(x)+shortcut(x))`다. 모든 shortcut이 파라미터 없는 identity라고 설명하면 틀린다. [구현](https://github.com/huggingface/transformers/blob/v4.18.0/src/transformers/models/resnet/modeling_resnet.py)

## 학습 설정: 원 논문과 HF 가중치의 이력을 분리

이 체크포인트는 이미지 분류 사전학습 모델이다. 공개 카드에 특정 학습 실행의 로그·recipe가 연결되어 있지 않다. 따라서 다음 원 논문 조건을 v1.5 체크포인트의 확정 설정으로 옮기지 않는다.

| 항목 | 이 HF 체크포인트 | 2015년 논문의 ImageNet 학습 설명 |
|---|---|---|
| 데이터 | ImageNet-1k | 약 128만 학습 이미지, 1,000클래스 |
| epoch | 미공개 | 해당 설명에서 명시하지 않음 |
| iteration / optimizer step | 미공개 | 최대 600,000 iteration |
| batch size | 미공개 | 256 |
| optimizer | 미공개 | SGD, momentum 0.9 |
| learning rate / scheduler | 미공개 | 0.1 시작, 오류가 정체되면 10분의 1 |
| weight decay | 미공개 | 0.0001 |
| gradient accumulation | 미공개 | 해당 설명에서 확인 불가 |
| 학습 precision / 하드웨어 | 확인 불가 | 이번 조사에서 실행별 조건 확인 불가 |
| 후속 SFT·DPO·RL·LoRA | 보고되지 않음 | 이 분류 모델의 기본 학습 설명에 해당 없음 |

근거: [카드](https://huggingface.co/microsoft/resnet-50/blob/34c2154c194f829b11125337b98c8f5f9965ff19/README.md), [원 논문 §3.4·§4.1](https://arxiv.org/html/1512.03385v1). config의 `torch_dtype=float32`는 저장·로드 관련 값이며 학습 전체가 FP32였다는 증거로 사용하지 않았다. batch와 iteration만으로 이 체크포인트의 epoch를 계산하지 않는다.

## 전처리와 평가의 한계

[고정 전처리 설정](https://huggingface.co/microsoft/resnet-50/blob/34c2154c194f829b11125337b98c8f5f9965ff19/preprocessor_config.json)은 size=224, crop_pct=0.875, RGB 평균 `[0.485,0.456,0.406]`, 표준편차 `[0.229,0.224,0.225]`를 제공한다. 설정의 feature extractor 이름은 `ConvNextFeatureExtractor`이지만 모델 구조를 ConvNeXt로 바꾸는 것은 아니다. 입력 전처리와 네트워크 유형을 구분해야 한다.

원 논문은 ImageNet validation 5만 장에 top-1·top-5 오류를 평가하며 10-crop·다중 scale 등의 조건을 구분한다. 유명한 3.57% top-5 오류는 ensemble의 test 결과라서 이 단일 HF ResNet-50 v1.5의 성적으로 적지 않았다. 카드에 인용된 v1.5 개선율도 조건이 다른 외부 구현 비교이며 이 파일의 실측 결과가 아니다. [논문](https://arxiv.org/html/1512.03385v1), [카드](https://huggingface.co/microsoft/resnet-50/blob/34c2154c194f829b11125337b98c8f5f9965ff19/README.md)

## 활용과 관련 모델 비교

이 모델은 ImageNet의 1,000개 클래스 중 하나로 이미지를 분류하거나, 별도 학습에서 CNN 특징 추출기의 출발점으로 활용할 수 있다. 사람의 모든 개념을 인식하는 범용 분류기가 아니며, 학습 범주 밖 입력에도 높은 점수를 낼 수 있다는 점을 고려해야 한다. 이 활용·제약 설명은 고정된 분류 head에서 도출한 분석이다. [클래스 목록](https://huggingface.co/microsoft/resnet-50/blob/34c2154c194f829b11125337b98c8f5f9965ff19/config.json)

[ViT-B/16](../10/2026-10-13-vit-base-patch16-224.md)이 패치를 Transformer로 처리한다면 이 모델은 국소 convolution과 공간 축소를 쌓는다. [DETR](../10/2026-10-29-detr-resnet-50.md)은 backbone 뒤에서 물체별 클래스와 상자를 출력하지만, 여기서는 이미지 전체의 분류 점수를 출력한다. 결과의 용도가 다르므로 한 줄 정확도로 우열을 비교하지 않는다.

원문 링크·구성값·기존 기록과의 차이를 검토했다. 가중치·벤치마크를 실행하지 않아 지연 시간·VRAM·실측 정확도를 제시하지 않는다.
