## 구조와 계산

| 항목 | 확인값 |
|---|---|
| 총 파라미터 | Hub safetensors 메타데이터 494,032,768개, BF16 |
| 비임베딩 파라미터 | 카드 약 0.36B |
| 유형·층수 | Dense decoder-only, 24층 |
| hidden / FFN | 896 / 4,864, SwiGLU |
| Q / KV heads | 14 / 2, GQA |
| head dimension | `896÷14=64`: 계산값 |
| Q당 KV 공유 | `14÷2=7`개 Q head가 한 KV head를 공유: 계산값 |
| context | 32,768 position |
| 위치 표현 | RoPE, theta=1,000,000, mRoPE 사용 안 함 |
| attention | causal, attention dropout 0.0, QKV bias 있음 |
| sliding window | 설정값은 있으나 `use_sliding_window=false`, 활성화됐다고 읽지 않음 |
| normalization | RMSNorm, epsilon 1e-6 |
| 어휘·임베딩 | vocab 151,936, 입력·출력 임베딩 공유 |
| MoE·멀티모달 encoder | 없음 |

[고정 config](https://huggingface.co/Qwen/Qwen2.5-0.5B/blob/060db6499f32faf8b98477b0a26969ef7d8b9987/config.json), [카드](https://huggingface.co/Qwen/Qwen2.5-0.5B/blob/060db6499f32faf8b98477b0a26969ef7d8b9987/README.md), [Hub 메타데이터](https://huggingface.co/api/models/Qwen/Qwen2.5-0.5B), [Qwen2 공식 라이브러리 코드](https://github.com/huggingface/transformers/blob/v4.45.2/src/transformers/models/qwen2/modeling_qwen2.py). 라이브러리 태그는 구조 확인용이며 실제 학습 commit을 뜻하지 않는다.

decoder는 앞서 나온 토큰만 보며 다음 토큰을 예측한다. GQA는 질문 역할의 Q head를 줄이지 않고 참고 정보인 K·V를 여러 Q head가 공유한다. 같은 head dimension의 14-KV-head MHA를 가정하면 KV cache 원소 수 비율은 `2÷14=1/7`이다. 이는 KV cache 부분의 이론 비교이며 모델 전체 VRAM이나 실제 속도가 7배 개선된다는 뜻은 아니다.

공유 임베딩 행렬 크기는 `151936×896=136134656`개다. 총계에서 빼면 `494032768−136134656=357898112`개로 카드의 비임베딩 약 0.36B와 부합한다. 공유 행렬을 입력·출력에 각각 두 번 세지 않았다. 계산 가정은 config의 tied embeddings와 Hub 총 파라미터 메타데이터다. [config](https://huggingface.co/Qwen/Qwen2.5-0.5B/blob/060db6499f32faf8b98477b0a26969ef7d8b9987/config.json), [API](https://huggingface.co/api/models/Qwen/Qwen2.5-0.5B)

## 학습: 시리즈 설명을 개별 모델 실행 기록으로 바꾸지 않기

| 항목 | 사전학습본에서 확인 가능한 범위 |
|---|---|
| 목적 | causal language modeling 사전학습 |
| 데이터 규모 | 공식 발표는 시리즈의 사전학습 데이터가 최대 18T tokens라고 설명. 이 HF revision의 정확한 소비 토큰 수는 확인 불가 |
| epoch / optimizer step | 개별 0.5B 실행의 명시값 확인 불가 |
| batch size / gradient accumulation | 개별 실행값 확인 불가 |
| LR / scheduler / optimizer | 정확한 0.5B 재현 recipe·실행값 확인 불가 |
| precision | 배포 가중치 BF16. 이를 전 학습 연산 precision으로 단정하지 않음 |
| 학습 장비 | 개별 실행 GPU 종류·수·시간 확인 불가 |
| SFT·DPO·RL·LoRA | 오늘 기본 체크포인트에 적용된 후속 단계 없음으로 구분. Instruct 학습값을 가져오지 않음 |

[모델 단계 설명](https://huggingface.co/Qwen/Qwen2.5-0.5B/blob/060db6499f32faf8b98477b0a26969ef7d8b9987/README.md), [시리즈 발표](https://qwenlm.github.io/blog/qwen2.5/), [기술 보고서](https://arxiv.org/html/2412.15115v2).

기술 보고서의 후속 학습 절은 100만 개 이상의 SFT 예제, SFT 2 epoch와 강화학습 등을 설명한다. 이 수치는 **오늘 사전학습본의 epoch가 아니다**. 24층은 구조의 깊이이며 학습 반복 횟수도, 생성 step 수도 아니다. 데이터 혼합과 반복 이력 없이 18T와 데이터셋 크기를 나누어 epoch를 추정하지 않았다. [보고서 후속 학습 절](https://arxiv.org/html/2412.15115v2)

## 평가의 범위와 실제 활용

보고서 Table 10은 작은 **instruction-tuned** 모델 비교로 MMLU-Pro, MMLU-redux, GSM8K, HumanEval 등을 다룬다. 표의 0.5B 열 제목이 축약돼 있어도 오늘 Base의 점수로 옮기지 않았다. 공식 발표의 72B·API 모델 수치도 이 0.5B의 결과가 아니다. 이 조사에서 해당 Base revision에 일대일 대응하는 평가 설정·점수를 확인하지 못했으므로 정량 성능은 확인 불가로 남긴다. 데이터셋뿐 아니라 few-shot·prompt·decoding·Base/Instruct 여부가 같아야 비교가 성립한다. [보고서 Table 10과 절 제목](https://arxiv.org/html/2412.15115v2), [공식 발표](https://qwenlm.github.io/blog/qwen2.5/)

시리즈의 최대 128K 소개와 달리 오늘 config·모델별 카드의 context는 **32,768**이다. 컨텍스트를 지원한다는 사실만으로 긴 문서의 모든 정보를 정확히 사용한다고 보장할 수 없다. [고정 카드](https://huggingface.co/Qwen/Qwen2.5-0.5B/blob/060db6499f32faf8b98477b0a26969ef7d8b9987/README.md)

기존 [TinyLlama-1.1B-Chat](2026-11-15-tinyllama-1-1b-chat-v1-0.md)은 대화 후속 학습본이고 오늘 모델은 Base다. 크기만 보고 대화 품질 우열을 매기기 어렵다. 분석상 소형 LM 실험, 도메인 추가 학습, 제한된 환경에서의 생성 연구 출발점으로 활용할 수 있다. 사용자 지시 준수·사실성·한국어 품질은 별도 검증이 필요하다. 실측하지 않은 처리량·VRAM·벤치마크 점수는 제시하지 않았다.
