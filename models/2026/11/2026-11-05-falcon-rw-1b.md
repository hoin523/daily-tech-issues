# Falcon-RW-1B: 24층 Transformer로 살펴보는 웹 데이터 사전학습

조사일: 2026-11-05 (한국 시간)

## 선정 이유와 모델 식별

Hugging Face 공개 지표를 조사한 시점에 다운로드 5,349회, 좋아요 120개를 확인했다. 다운로드는 최근 한 달 지표이며 좋아요는 누적값이다. 최신 트렌딩 상위 모델이라는 뜻은 아니며, 계속 사용되는 연구용 원본 모델 중 기존 분석과 개발 조직이 겹치지 않는 대상을 골랐다. 이 수치는 성능을 증명하지 않는다. [모델 페이지](https://huggingface.co/tiiuae/falcon-rw-1b), [조회 API](https://huggingface.co/api/models/tiiuae/falcon-rw-1b)

## 구조: Falcon이라는 이름만으로 MQA를 가정하면 안 된다

| 항목 | 값 / 읽는 방법 |
|---|---|
| 파라미터 | 공식 카드 약 1B. 정밀한 정수 총량은 확인 불가. Dense 모델이며 MoE 전문가 선택은 없다. |
| Transformer 레이어 | 24 |
| hidden dimension | 2,048 |
| attention heads | 32 |
| KV heads | 32. `multi_query=false`이고 구현의 기본 KV head 수는 attention head 수를 따른다. |
| head dimension | 64 = 2,048 ÷ 32 |
| FFN 중간 차원 | 8,192 = 4 × 2,048. 코드의 `dense_h_to_4h`에서 유도. GELU 사용. |
| 학습 시퀀스 길이 | 2,048 토큰. 더 긴 문맥에서 품질이 보장된다는 의미는 아니다. |
| 위치 정보 | ALiBi (`alibi=true`) |
| attention | causal full multi-head attention. 공식 카드는 FlashAttention 사용을 설명한다. |
| 블록 배치 | `parallel_attn=false`: attention 다음에 MLP를 순차 적용한다. |
| 어휘 / tokenizer | 50,304 / 카드상 GPT-2 tokenizer |
| 기타 | bias 사용, attention·hidden dropout 0, LayerNorm epsilon 1e-5 |

근거: [config](https://huggingface.co/tiiuae/falcon-rw-1b/blob/e4b9872bb803165eb22f0a867d4e6a64d34fce19/config.json), [설정 기본값](https://huggingface.co/tiiuae/falcon-rw-1b/blob/e4b9872bb803165eb22f0a867d4e6a64d34fce19/configuration_falcon.py), [attention·MLP·decoder 구현](https://huggingface.co/tiiuae/falcon-rw-1b/blob/e4b9872bb803165eb22f0a867d4e6a64d34fce19/modeling_falcon.py), [카드의 구조 표](https://huggingface.co/tiiuae/falcon-rw-1b/blob/e4b9872bb803165eb22f0a867d4e6a64d34fce19/README.md#model-architecture-and-objective). 표의 나눗셈·곱셈은 구성과 코드에서 계산한 값이다.

입력 토큰은 2,048차원 벡터가 되고 24개 블록을 통과한다. 각 attention head는 이전 토큰 중 어떤 정보를 참고할지 계산하며, 미래 토큰은 가린다. 이 모델은 Q뿐 아니라 K와 V도 32개 head로 구성하므로 여러 Q가 하나의 KV를 공유하는 MQA와 다르다. MLP는 각 위치의 표현을 4배로 넓혔다가 줄이며 변환한다. 마지막에는 다음 토큰의 확률을 예측한다. [구현](https://huggingface.co/tiiuae/falcon-rw-1b/blob/e4b9872bb803165eb22f0a867d4e6a64d34fce19/modeling_falcon.py)

ALiBi는 attention 점수에 거리 관련 편향을 넣는 방식이다. FlashAttention은 attention 계산의 메모리 접근을 효율화하는 구현 방식으로, 레이어 수나 학습 epoch를 뜻하지 않는다. 이 두 요소를 각각 위치 처리와 계산 구현으로 구분해서 읽어야 한다. [공식 구조 설명](https://huggingface.co/tiiuae/falcon-rw-1b/blob/e4b9872bb803165eb22f0a867d4e6a64d34fce19/README.md#model-architecture-and-objective)

## 학습 설정: 공개된 토큰 수와 공개되지 않은 epoch

아래는 이 체크포인트의 사전학습 설정이다. 카드에서 후속 SFT·DPO·RL·LoRA 단계는 보고하지 않으므로 해당 단계를 거쳤다고 간주하지 않는다.

| 항목 | 사전학습 공개 내용 |
|---|---|
| 목적 | causal language modeling, 다음 토큰 예측 |
| 데이터 / 토큰 | 필터링·중복 제거한 RefinedWeb, 350B 토큰 |
| epoch | 검토한 카드·논문에서 이 실행의 값 미공개 |
| optimizer step 총수 | 미공개 |
| batch size | 512, 처음 4B 토큰에 걸쳐 batch ramp-up |
| gradient accumulation / 장치별 microbatch | 미공개 |
| optimizer / weight decay | AdamW / 0.1 |
| learning rate | 2e-4, 500M 토큰 warm-up 후 cosine decay로 2e-5까지 |
| precision | bfloat16 |
| 하드웨어 / 병렬화 | A100 40GB 32개, AWS SageMaker P4d. 이 실행은 data parallelism + ZeRO |
| 학습 소프트웨어 | 커스텀 Gigatron |

근거: [고정 카드의 학습 설정](https://huggingface.co/tiiuae/falcon-rw-1b/blob/e4b9872bb803165eb22f0a867d4e6a64d34fce19/README.md#training-details). 전체 재현 가능한 실행 설정 파일은 이번 조사에서 확인하지 못했다.

목표 batch를 512개 시퀀스, 각 길이 2,048로 채운다고 가정하면 update당 토큰 수는 `512 × 2,048 = 1,048,576`이다. 이는 계산상 목표치이고 실제 모든 update가 이 크기였다는 뜻은 아니다. 초기 batch ramp-up이 있으므로 `350B ÷ 1,048,576`을 실제 optimizer step 수로 기록하지 않았다. 또한 24개 레이어는 네트워크 깊이이며 데이터 반복 횟수인 epoch와 관계없는 수치다.

## 데이터와 평가를 읽는 기준

RefinedWeb 연구의 핵심은 웹 문서의 필터링과 중복 제거다. 모델의 350B 학습 토큰과 논문에서 구축한 전체 데이터 규모를 혼동하면 안 된다. 데이터 처리의 영향을 분석하려는 실험이라는 점이 이 모델을 읽는 출발점이다. [공식 논문 §3–4](https://arxiv.org/html/2306.01116v1)

논문은 EAI evaluation harness 기반 zero-shot 평가와 과제 집계를 사용한다. HellaSwag·LAMBADA·Winogrande 등 과제의 결과는 대화형 지시 이행 평가와 다르다. 내부 통제 실험과 외부 모델의 인용 결과도 비교 조건이 같지 않다. 특히 1B 모델의 27B-token 소규모 ablation 결과를 최종 350B-token Falcon-RW-1B의 점수로 옮겨 적어서는 안 된다. 이번 글에서는 조건이 다른 점수를 하나의 순위로 합치지 않았다. [공식 논문 §4 및 부록 F](https://arxiv.org/html/2306.01116v1)

## 활용과 제약, 이전 모델과의 비교

웹 데이터 정제의 효과를 공부하거나 작은 영어 기본 언어 모델의 표현·다음 토큰 예측을 분석하는 데 적합하다. 사용자 지시를 따르는 채팅 모델로 학습된 체크포인트는 아니므로 바로 대화 서비스의 품질을 기대하기 어렵다. 영어 중심 학습과 웹의 편향도 제약이다. 카드의 오래된 다른 모델 추천을 현재 최선의 선택으로 해석하지 않았다. [공식 용도·한계](https://huggingface.co/tiiuae/falcon-rw-1b/blob/e4b9872bb803165eb22f0a867d4e6a64d34fce19/README.md#uses)

이전에 다룬 [Pythia-70M](2026-11-01-pythia-70m.md)과 함께 보면 사전학습 기본 모델을 읽는 연습이 된다. 다만 크기와 데이터가 달라 두 모델의 점수 차이를 데이터 정제 하나의 효과로 해석할 수 없다. Falcon-RW-1B의 장점은 24층 구조와 학습 하이퍼파라미터를 공개 자료로 연결해 볼 수 있다는 데 있다.

가중치 다운로드, 추론 벤치마크, 학습 실행은 수행하지 않았다. 따라서 처리 속도나 실제 VRAM 사용량을 실측값으로 제시하지 않는다. 기존 `models`·`issues` 전체 기록을 확인했으며 동일 모델의 구조 분석 및 양자화·미러 변형 분석과 중복되지 않는다.
